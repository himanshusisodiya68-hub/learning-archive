# Reference books to upload

Put the PDFs in one Google Drive folder, for example `learning-archive-books`, with a subfolder per subject (`physics`, `maths`, `chemistry`, `english`). Any file name works; including the edition helps.

★ = needed for phase 1 (Class 10–12 to JEE and Olympiad). Upload these first.
